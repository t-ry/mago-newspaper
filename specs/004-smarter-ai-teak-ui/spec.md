# Feature Specification: AI品質向上とチークUI

**Created**: 2026-09-22 | **Status**: 実装済み

写真選定と記事編集に使うAIを上位モデルへ更新し、サービス全体をチーク材の温かみが伝わる見た目へ変更する。

## User Scenarios & Testing

### US1 より質の高いAI編集を使う（P1）

1. 親が写真とメモを送ると、上位モデルが写真を選び記事を生成する。
2. AIの応答は既存のJSON契約と写真ID検証を通過する。
3. 公開画面で利用モデルを確認できる。

### US2 温かい編集室で新聞を作る（P1）

1. デスクトップではチーク材を思わせる編集室と生成りの紙面が表示される。
2. スマホでも読みやすさと主要操作のコントラストが保たれる。
3. 既存のカメラ、編集、承認、PDF、模擬注文フローが維持される。

## Requirements

- FR-001: OrcaRouterの標準モデルを、画像入力と構造化出力を実検証した上位モデルへ変更する。
- FR-002: モデル名は環境変数で引き続き差し替え可能にする。
- FR-003: チークの濃茶、蜂蜜色、生成りを一貫した配色として使う。
- FR-004: 本文へ丸みのある日本語フォント、新聞見出しへ明朝体を使う。
- FR-005: デスクトップと390px幅のモバイルでレイアウトを維持する。

## Success Criteria

- SC-001: OrcaRouterへJPEG data URIを送り、記事と有効な写真IDを取得できる。
- SC-002: 公開`/api/config`が新しいモデル名を返す。
- SC-003: 公開URLのモバイルE2Eが全工程で成功する。
- SC-004: 1440pxと390pxの画面で文字切れと横スクロールがない。
