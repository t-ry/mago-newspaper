# 孫ニュースペーパ — MVP要件

## ユーザーが指定した内容

- 親が撮った子供の写真をAIが選定・編集し、祖父母へ届ける。
- 必須体験: AI写真選定・記事編集、A4新聞PDF、親の承認、印刷・郵送API。
- 郵送事業者は未定。今回のデモは模擬注文で進める（2026-09-22確認）。
- 応募条件: OrcaRouter APIを組み込む。
- 締切: 2026-09-22 15:00 JST。GitHub公開URLとQiita記事URLを提出。
- ユーザーのREADME原案は`docs/product-vision.md`に保存。

## 今回の実装判断

写真一括アップロードを入口に、AIで最大3枚を選び、記事とA4紙面を生成する。動画と端末の定期収集は次段階。原案にある事実捏造防止・親の最終確認を優先する。
